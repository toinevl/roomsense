RoomSense Architecture

Terabee room-occupancy sensor data — C-level dashboard + live telemetry showcase

API Surface (12 endpoints)

  • • GET /api/health — build SHA + table status
  • • GET /api/rooms — latest occupancy per room
  • • GET /api/rooms/:id/occupancy — snapshot series
  • • GET /api/rooms/:id/readings — raw telemetry
  • • GET /api/rooms/:id/reservations — bookings
  • • GET /api/rooms/:id/reviews — room reviews
  • • POST /api/reviews — submit review
  • • GET /api/kpis — utilization/ghost/wasted-euro KPIs
  • • GET /api/sources — adapter registry status
  • • GET /api/presence — user presence by building
  • • GET /api/users/:id/friends — friend links
  • • GET+PATCH /api/users/:id/privacy — privacy settings
  • • POST /api/simulate/tick — advance demo clock

Table Storage Schema

  • • Rooms — PartitionKey=building, RowKey=roomId
  • • SensorReadings — PK=deviceId, RK=deviceId-ts
  • • OccupancySnapshots — PK=roomId, RK=roomId-ts
  • • Reservations — PK=roomId, RK=roomId-startTs
  • • Sources — PK=source, RK=sourceId
  • • UserPresence — PK=building, RK=userId
  • • FriendLinks — PK=userId, RK=friendId
  • • RoomReviews — PK=roomId, RK=reviewId
  • • UserPrivacy — PK=userId, RK=settings

Frontend Pages (11 routes)

  • • #dashboard — KPI tiles, utilization charts
  • • #live — room grid with live occupancy polling
  • • #architecture — system overview (visual)
  • • #finder — room finder with click-to-select
  • • #report — semester in review
  • • #trust — trust & transparency metrics
  • • #wrapped — RoomSense Wrapped (gamified)
  • • #booking-success — confirmation page
  • • #friends — friend links + presence
  • • #reviews — room reviews + ratings
  • • #privacy — privacy settings

Deploy & CI/CD

  • • Bicep IaC — rgRoomSense, West Europe
  • • OIDC federation (no long-lived secrets)
  • • API: func CLI publish (Consumption Y1)
  • • Frontend: SWA publish profile
  • • Platform CORS via az functionapp cors add
  • • Seed: pnpm seed:azure uploads to Tables
  • • Verify: gh run watch + smoke test
